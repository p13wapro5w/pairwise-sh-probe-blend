# pairwise-sh-probe-blend

走廊尽头的灯突然在墙上留下一块方形亮斑，探针四面体剖分跨过了墙体，墙两侧的探针被连在同一个单元里；球谐只存了 4 个系数，方向性强的灯在背光面仍然发亮；插值权重按距离倒数计算后没有归一化，靠近边界的像素整体过曝；边界处缺失的探针被填成零，墙面出现一条黑边；动态物体经过时探针不更新，角色身上一直带着走廊的暖色；不同区域用了不同阶数的球谐，切换处颜色突变；探针数据在 sRGB 空间烘焙，插值后中间调偏亮；三角形边界两侧权重不连续，移动相机时墙面出现跳变的方块；体积探针没有记录高度层，楼梯上下两层的照明混在一起；重新烘焙后运行时缓存没有失效，看到的还是旧探针。render/sh_probe_blend.py 是核心，tests/test_sh_probe_blend.py 15个红。要修的是：按墙体剖分；统一九系数；权重归一；缺失探针回退；动态探针；统一阶数；线性空间；边界连续；按高度分层；版本失效。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
